홈페이지 관리자

GitHub 토큰으로 로그인합니다. 토큰은 이 브라우저에만 저장되고 다른 곳으로 보내지 않습니다.

토큰이 없나요? 발급 방법 보기
  1. GitHub 토큰 발급 페이지를 엽니다.
  2. Token name에 cusmos-admin, Expiration은 원하는 기간을 고릅니다.
  3. Repository access에서 Only select repositories를 고르고 저장소를 선택합니다.
  4. Permissions에서 Contents를 Read and write로, Pages를 Read-only로 바꿉니다.
  5. Generate token을 누르고 나온 토큰을 복사해 위 칸에 붙여 넣습니다.

관리자로 쓸 사람의 GitHub 계정이 저장소 협업자로 초대되어 있어야 합니다.
